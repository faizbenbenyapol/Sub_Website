# ตัดยัง? — Design System

> อ้างอิง: `docs/01-requirements.md`, `docs/02-architecture.md` · ทิศทางภาพ **dark + vivid + glass** เลือกแล้วในรอบออกแบบ 6 ต.ค. 69 (เอกสารนี้ทำให้เป็นกฎที่ใช้ได้ทั้งทีม ไม่ได้เปิดให้เลือกใหม่)
> Tokens อยู่ที่ `src/app/globals.css` — **ห้ามใส่ค่าสี hex ตรงใน component** ใช้ชื่อ token เท่านั้น

## 1. ตัวตนของงาน

| คำถาม | คำตอบ |
|---|---|
| มันคืออะไรจริง ๆ | สมุดจดว่า "เดือนนี้จะโดนตัดเงินอะไร วันไหน เท่าไร" ของคนที่มี subscription 3–10 รายการ |
| ใครใช้ ใช้ตอนไหน | นักศึกษา/คนทำงาน เปิดบนมือถือตอนได้อีเมลเตือน หรือตอนเห็นยอดบัตรแล้วสงสัยว่า "อันนี้ค่าอะไร" |
| หน้าที่หลักของแอป | ตอบคำถามเดียวให้เร็วที่สุด: **"อะไรจะตัดเงินเร็ว ๆ นี้ และฉันยังใช้มันอยู่ไหม"** |
| โลกจริงของเรื่องนี้ | สลิปโอนเงิน, statement บัตรเครดิต, ใบเสร็จที่มีรอยปรุ, SMS "ตัดบัตร xxx-1234 ฿419", QR พร้อมเพย์ |
| ของจริงที่ต้องแสดง | ชื่อบริการจริง (Netflix, Spotify, YouTube Premium, iCloud+), ราคาบาทจริง, วันที่ไทย, "อีก 3 วัน" |

**สิ่งที่คนต้องจำได้จากหน้าจอนี้:** ตัวเลข "อีก N วัน" และยอดเงินที่ใหญ่และเป็น mono แบบหน้าจอ ATM ส่วนรายการที่จะตัดเงินหน้าตาเหมือน**สลิปที่มีรอยปรุ**

### Signature element: สลิปตัดเงิน (Charge stub)

รายการที่ใกล้ตัดเงินไม่ได้เป็นการ์ดมนธรรมดา แต่เป็นแถบ "สลิป" ที่มีเส้นปรุ (dashed) คั่นตรงกลาง ฝั่งซ้ายคือบริการ ฝั่งขวาคือวันและยอด เหมือนต้นขั้วใบเสร็จ

```
┌──────────────────────────┬╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┐
│ [N] Netflix              ╎  อีก 3 วัน     │
│     Premium · บัตร KBank ╎  ฿419.00       │
│                          ╎  ศ. 9 ต.ค.     │
└──────────────────────────┴╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┘
```
- เส้นปรุ `border-left: 1.5px dashed var(--line-strong)` + รอยเว้าครึ่งวงกลมบนและล่าง (pseudo-element สีพื้นหน้า) — ใช้**เฉพาะ** upcoming list ใน Dashboard, รายการในวันของปฏิทิน และอีเมลแจ้งเตือน
- ไม่ใช้กับรายการอื่น เพื่อให้ "สลิป" แปลว่า "จะโดนตัดเงิน" เสมอ

## 2. สี

ตั้งชื่อตามความหมายในแอป ไม่ใช่ primary/secondary

| Token | Hex | ความหมาย / ใช้ที่ |
|---|---|---|
| `--night` | `#0B0B0F` | พื้นหน้าเว็บ (กลางคืน = เวลาที่คนไล่ดูยอดบัตร) |
| `--glass` | `rgba(255,255,255,0.05)` | พื้นการ์ด/แผงบนพื้น night (ค่าที่ตาเห็นจริง ≈ `#18181C`) |
| `--glass-strong` | `rgba(255,255,255,0.08)` | hover ของแถว, input, เมนูที่เปิดอยู่ |
| `--line` | `rgba(255,255,255,0.09)` | ขอบการ์ดแก้ว, เส้นคั่นแถว |
| `--line-strong` | `rgba(255,255,255,0.22)` | เส้นปรุของสลิป, ขอบ input ตอนปกติ |
| `--text` | `#F4F4F6` | ตัวหนังสือหลัก |
| `--text-muted` | `#A6A6B0` | คำอธิบาย, label รอง |
| `--text-faint` | `#8A8A94` | timestamp, placeholder (ห้ามใช้กับข้อมูลที่ต้องอ่าน) |
| `--slip` | `#3B4CF5` | **บล็อกฮีโร่สีทึบ** — การ์ดยอดรวมต่อเดือน, หน้าจ่ายเงิน (สีโทนเดียวกับ Thai QR) |
| `--due` | `#FF8A3D` | **ใกล้ตัดเงิน / เตือน** — ป้าย "อีก ≤ 3 วัน", "หมดทดลองใช้", การ์ดตัวช่วยประหยัด |
| `--paid` | `#C8F169` | **action หลัก + จ่ายแล้ว/ปลอดภัย** — ปุ่มหลัก, focus ring, สถานะ "จ่ายแล้ว" |
| `--danger` | `#FF6B6B` | error, ลบ, ระงับบัญชี |
| `--link` | `#7C8BFF` | ลิงก์ในเนื้อความบนพื้นมืด (น้ำเงิน slip สว่างขึ้นให้อ่านได้) |

**contrast (WCAG AA ≥ 4.5 สำหรับข้อความปกติ)** — ตรวจด้วยสูตร WCAG 2.x แล้ว:

| คู่สี | อัตราส่วน | ผล |
|---|---|---|
| text บน night / บน glass | 17.9 / 16.1 | ✅ |
| text-muted บน glass | 7.3 | ✅ |
| text-faint บน glass | 5.2 | ✅ (ใช้กับข้อความรองได้) |
| night บน paid (ปุ่มหลัก) | 15.2 | ✅ |
| night บน due | 8.4 | ✅ |
| due / paid / danger / link บน glass | 7.6 / 13.7 / 6.4 / 5.9 | ✅ |
| ขาวบน slip | 5.9 | ✅ |
| paid บน slip | 4.6 | ✅ เฉียดเกณฑ์ → ใช้กับตัวเลขใหญ่ ≥ 24px เท่านั้น |

**กฎการใช้สี**
- ทั้งหน้ามี**บล็อกสีทึบได้ที่เดียว** (การ์ด slip ใน Dashboard หรือการ์ด due ของตัวช่วยประหยัด ไม่ใช่ทั้งคู่ในจอเดียว) ที่เหลือเป็น glass
- **ห้ามทำกล่องพื้นสีอ่อนตัวหนังสือสีเดียวกัน** (pastel tinted callout) — ผู้ใช้ปฏิเสธไปแล้ว ถ้าต้องเตือนให้ใช้ glass + จุดหรือเส้นซ้ายสี `--due` + ข้อความสี `--text`
- สถานะห้ามสื่อด้วยสีอย่างเดียว ต้องมีคำกำกับเสมอ ("อีก 2 วัน", "จ่ายแล้ว", "ยกเลิกแล้ว")
- ไม่มี gradient บนตัวหนังสือ ไม่มีเงา `shadow-lg` สีเทาฟ้า

### พื้นหลังเรืองแสง (glow)
อยู่ที่ `body` เท่านั้น เป็น radial gradient 3 จุดที่**ไม่ขยับ**: น้ำเงิน `--slip` มุมซ้ายบน, ส้ม `--due` ขวากลาง, เขียว `--paid` ล่างซ้าย ความทึบ 18–22% เบลอ 120px ขึ้นไป · ไม่ใส่ blob ซ้ำในการ์ดหรือ section · หน้า admin ลดเหลือจุดเดียว (หน้าทำงาน ไม่ใช่หน้าโชว์)

### กระจก (glass)
`background: var(--glass); border: 1px solid var(--line); backdrop-filter: blur(16px);`
- ใช้กับการ์ด แผง dialog และ nav
- **ห้ามกระจกซ้อนกระจก** (ข้างในการ์ดแก้วให้ใช้เส้นคั่น ไม่ใช่การ์ดแก้วอีกชั้น)
- เบราว์เซอร์ที่ไม่รองรับ `backdrop-filter` ได้สี `#18181C` ทึบแทน (`@supports not`)

## 3. ตัวอักษร

| บทบาท | ฟอนต์ | น้ำหนัก | เหตุผล |
|---|---|---|---|
| หัวข้อ / ชื่อบริการ / ปุ่ม | **Bai Jamjuree** | 500, 600, 700 | ไทยมีเหลี่ยม คม ให้ความรู้สึกเครื่องมือการเงิน ไม่หวาน |
| เนื้อความ / ฟอร์ม / ตาราง | **IBM Plex Sans Thai** (+ IBM Plex Sans สำหรับละติน) | 400, 500, 600 | อ่านง่ายบนมือถือ ไทย-อังกฤษเป็นตระกูลเดียวกัน |
| ตัวเลขเงิน / วัน / นับถอยหลัง | **IBM Plex Mono** | 500, 600 | ตัวเลขกว้างเท่ากันแบบ statement/ATM — นี่คือพระเอกของแอป |

โหลดผ่าน `next/font/google` (ดู `src/app/layout.tsx`) ระบุน้ำหนักที่ใช้จริงเท่านั้น เพื่อไม่ให้เบราว์เซอร์ปลอมตัวหนา

**Type scale (อัตราส่วน 1.25, base 16px)**

| Token | ขนาด / line-height | ใช้ที่ |
|---|---|---|
| `text-caption` | 14 / 1.7 | timestamp, helper text (ไทยห้ามต่ำกว่า 14) |
| `text-body` | 16 / 1.75 | เนื้อความ, input |
| `text-lead` | 20 / 1.6 | ชื่อบริการในรายการ, หัวการ์ด |
| `text-h3` | 25 / 1.35 | หัว section |
| `text-h2` | 31 / 1.3 | หัวหน้า |
| `text-h1` | 39 / 1.25 | หัวหน้า landing |
| `text-figure` | 48–64 (mono) / 1.1 | ยอดรวมต่อเดือน, "อีก 3 วัน" |

กฎ: `letter-spacing: 0` เสมอ (ไทยห้ามบีบ) · ไม่มี ALL-CAPS eyebrow · ตัวเลขเงินใช้ `tabular-nums` และชิดขวาในตาราง · เงินแสดง `฿419.00` (มีทศนิยม 2 ตำแหน่งเสมอในตาราง/สลิป, ในประโยคใช้ `฿419` ได้) · ความยาวบรรทัดเนื้อความ ≤ 65 ตัวอักษร

**วันที่ภาษาไทย:** สั้น `ศ. 9 ต.ค.` (สลิป, ปฏิทิน) · ยาว `ศุกร์ 9 ตุลาคม 2569` (หน้ารายละเอียด, อีเมล) · ใช้ `Intl.DateTimeFormat('th-TH-u-ca-buddhist', { timeZone: 'Asia/Bangkok' })` · ระยะเวลาสัมพัทธ์: `วันนี้`, `พรุ่งนี้`, `อีก N วัน`

## 4. Spacing, radius, motion

- **Spacing** ฐาน 4px: `4 8 12 16 24 32 48 64` · ใน section อัดชิด (12–16) ระหว่าง section ห่าง (48–64) เพื่อให้เห็นจังหวะ ไม่ใช่ระยะเท่ากันหมด
- **Radius มีลำดับ:** การ์ดใหญ่/บล็อกฮีโร่ `28px` · การ์ดปกติ/dialog `24px` · input/ปุ่ม `14px` · ป้ายสถานะ `8px` (ไม่ใช่ pill กลมสุด) · avatar ตัวอักษรของบริการ `12px` (สี่เหลี่ยมมน เหมือนไอคอนแอป)
- **Motion** เฉพาะที่ตอบการกระทำ: เปิด/ปิด dialog, toast, กดปุ่ม (scale 0.98), แถวที่เพิ่งบันทึกกะพริบขอบ `--paid` หนึ่งครั้ง · 120–200ms `ease-out` · **ไม่มี** fade-up ตอน scroll, ไม่มีการ์ดยกตอน hover, ไม่มีตัวเลขวิ่ง · `prefers-reduced-motion: reduce` → ปิด transition ทั้งหมด

## 5. Component

| Component | สเปก |
|---|---|
| **ปุ่มหลัก** | พื้น `--paid` ตัวหนังสือ `--night` Bai Jamjuree 600 · สูง ≥ 44px · ข้อความบอกผลที่เกิด: "เพิ่มรายการ", "บันทึกการเปลี่ยนแปลง", "ส่งอีเมลทดสอบ" (ห้าม "ตกลง"/"Submit") · หนึ่งจอมีปุ่มหลักได้หนึ่งปุ่ม |
| **ปุ่มรอง** | glass + ขอบ `--line-strong` ตัวหนังสือ `--text` |
| **ปุ่มอันตราย** | ตัวหนังสือ `--danger` บน glass; ปุ่มยืนยันใน dialog ลบใช้พื้น `--danger` ตัวหนังสือ `--night` |
| **Input** | label อยู่บนเสมอ (ไม่ใช้ placeholder แทน label) · พื้น `--glass-strong` ขอบ `--line-strong` radius 14 สูง 48 · focus: ขอบ 2px `--paid` · error: ขอบ `--danger` + ข้อความใต้ช่องบอกวิธีแก้ ("ราคาต้องเป็น 0 หรือมากกว่า") + `aria-describedby` · ช่องเงินมี `฿` นำหน้าและใช้ mono |
| **การ์ดแก้ว** | ตามข้อ 2 · padding 20 (มือถือ) / 24 (≥ 768) |
| **การ์ดฮีโร่ slip** | พื้น `--slip` ทึบ radius 28 มีวงกลมทึบ `--due` และ `--paid` ซ้อนมุมขวา (ตกแต่งจุดเดียวของหน้า) ข้างในคือยอดต่อเดือน `text-figure` mono สีขาว |
| **สลิปตัดเงิน** | ข้อ 1 · ป้ายนับถอยหลัง: ≤ 3 วัน สี `--due`, วันนี้ = `--due` + คำว่า "วันนี้" ตัวหนา, > 3 วัน สี `--text-muted` |
| **ป้ายสถานะ** | radius 8, ตัวหนังสือ 14 · มีจุดสี 8px นำหน้า + คำ · `ใช้งานอยู่` (paid), `ยกเลิกแล้ว` (faint), `ทดลองใช้ถึง 12 ต.ค.` (due), `จ่ายแล้ว` (paid), `ยังไม่จ่าย` (muted) |
| **โลโก้บริการ** | รูปจาก `logoUrl` ขนาด 40 (รายการ) / 64 (หน้ารายละเอียด) radius 12 พื้นขาว (โลโก้ส่วนใหญ่ออกแบบมาบนพื้นขาว) · ไม่มีรูป → สี่เหลี่ยม glass + ตัวอักษรแรก Bai Jamjuree 700 |
| **Toast** | ล่างกลางบนมือถือ (ระยะนิ้วโป้ง) ขวาล่างบน desktop · glass + เส้นซ้าย 3px ตามชนิด · ข้อความตรงกับปุ่ม: กด "ยกเลิกรายการ" → "ยกเลิก Netflix แล้ว" · `role="status"` |
| **Dialog ยืนยัน** | ใช้กับ ลบ / ยกเลิก / ระงับบัญชี เท่านั้น · หัวข้อเป็นคำถามที่มีชื่อของจริง: "ลบ Netflix ออกจากรายการ?" · บอกผลที่ตามมา ("กลุ่มหารที่ผูกไว้จะถูกลบด้วย") · โฟกัสเริ่มที่ปุ่มยกเลิก · ปิดด้วย Esc |
| **กราฟ** | สัดส่วนตามหมวด = **แท่งแนวนอนเรียงจากมากไปน้อย** (ไม่ใช้โดนัท) แสดงยอดบาทท้ายแท่ง · สีแท่งเดียว `--paid` ยกเว้นแท่งที่เลือกอยู่ · แกนและ grid สี `--line` · Admin: ผู้ใช้ใหม่รายวัน = เส้น, Top 10 = แท่งแนวนอน |

## 6. Layout และหน้าหลัก

**Navigation**
- มือถือ (< 768): **แถบล่าง 4 ช่อง** `ภาพรวม · รายการ · ปฏิทิน · ตั้งค่า` + ปุ่ม `+` ลอยเหนือแถบ (เพิ่มรายการ = action ที่ทำบ่อยสุด อยู่ในระยะนิ้วโป้ง) · กระดิ่งอยู่มุมขวาบน
- Desktop (≥ 1024): แถบบนแนวนอน ชื่อแอปซ้าย เมนูกลาง กระดิ่ง + ชื่อผู้ใช้ขวา · เนื้อหากว้างสูงสุด 1120px **ชิดซ้ายในคอนเทนเนอร์** ไม่จัดกลางทุกอย่าง
- Admin ใช้ sidebar ซ้าย (หน้าทำงานที่มีหลายเมนู) และตัดพื้นหลัง glow เหลือจุดเดียว

**รายการของฉัน (`/subscriptions`)** — เป็น**ตาราง/รายการมีเส้นคั่น** ไม่ใช่กริดการ์ด: โลโก้ · ชื่อ+แพ็กเกจ · วันตัดถัดไป · ราคา (ชิดขวา mono) · เมนู ⋯ · แท็บ `ใช้งานอยู่ / ยกเลิกแล้ว` · มือถือยุบเป็นสองบรรทัดต่อแถว

**ฟอร์มเพิ่มรายการ** — ขั้นแรกค้นหาบริการจากคลัง (ช่องค้นหา + รายการ) มีลิงก์ "ไม่มีในรายการ? เพิ่มเอง" · เลือกแล้วเติมราคา/รอบบิลให้ ผู้ใช้แก้ได้ · ฟิลด์ไม่บังคับ (ช่องทางจ่าย, วันหมดทดลอง, หมายเหตุ) ซ่อนใน "รายละเอียดเพิ่มเติม" · ปุ่มหลัก "เพิ่มรายการ" ติดล่างจอบนมือถือ

**ปฏิทิน (`/calendar`)** — กริด 7 คอลัมน์ เริ่มวันอาทิตย์ หัวคอลัมน์ `อา จ อ พ พฤ ศ ส` · ในช่องวัน: โลโก้เล็ก 20px สูงสุด 2 อัน + `+N` และยอดรวมของวันนั้น (mono) · วันนี้มีขอบ `--paid` · มือถือ: ช่องวันแสดงแค่จุดสี + ยอด, กดแล้วรายการของวันนั้นเลื่อนขึ้นเป็นสลิปด้านล่าง · ใช้ปุ่ม `<` `>` และคีย์บอร์ดลูกศรเลื่อนวันได้ (`role="grid"`)

**คลังบริการ (`/services`)** — ค้นหาอยู่บนสุด แท็บหมวดเลื่อนแนวนอนได้ · รายการเป็นกริด 2 คอลัมน์ (มือถือ) / 4 (desktop) โลโก้ + ชื่อ + "เริ่ม ฿99/เดือน" · ไม่มีคำอธิบายบริการ (ทุกคนรู้จัก Netflix อยู่แล้ว)

**รายละเอียดบริการ (`/services/[slug]`)** — หัว: โลโก้ 64 + ชื่อ + หมวด + "อัปเดตข้อมูล 8 ต.ค. 2569" · ตารางแพ็กเกจ (ชื่อ, ราคา, รอบบิล, ใช้ได้กี่คน) · **วิธียกเลิก** เป็น `<ol>` ตัวเลขใหญ่ mono ข้างแต่ละขั้น มี `id="cancel"` ให้ลิงก์จากอีเมลกระโดดมาตรงนี้ · ปุ่มหลัก "เพิ่มเข้ารายการของฉัน" (ไม่ได้ล็อกอิน → "เข้าสู่ระบบเพื่อเพิ่ม")

**หน้าจ่ายเงิน (`/pay/[token]`, P1)** — หน้าเดียวที่คนนอกเห็น ต้องเข้าใจภายใน 3 วินาที: บล็อก `--slip` ทึบเต็มความกว้าง "มายด์ขอเก็บค่า Netflix เดือน ต.ค." → ยอด `฿105.00` ใหญ่ → QR บนพื้นขาว 240px (สแกนได้แม้จอมืด) → "PromptPay 08x-xxx-1234 · ชื่อบัญชีจะขึ้นในแอปธนาคารตอนสแกน" → สถานะ `ยังไม่จ่าย/จ่ายแล้ว` · ไม่มี nav

**Admin** — ตารางเป็นหลัก ค้นหา + ปุ่ม "เพิ่มบริการ" ด้านบน · ฟอร์มแก้ราคาแพ็กเกจแสดงราคาเดิมข้างช่องใหม่ และบอกล่วงหน้าว่า "ราคาเดิมจะถูกเก็บในประวัติราคา" · ลบไม่ได้เพราะมีคนใช้ → dialog บอกจำนวนผู้ใช้และเสนอปุ่ม "ซ่อนบริการ" แทน

## 8. Accessibility (เกณฑ์ผ่าน)

- contrast ตามตารางข้อ 2 · focus ring `2px solid var(--paid)` + `outline-offset: 2px` มองเห็นทุก element ที่โฟกัสได้ (ห้าม `outline: none` โดยไม่มีตัวแทน)
- เป้ากด ≥ 44×44px บนมือถือ · ฟอร์มทุกช่องมี `<label>` · error ผูกด้วย `aria-describedby` และ `aria-invalid`
- `<html lang="th">` · หน้าละหนึ่ง `<h1>` · ไอคอนอย่างเดียวต้องมี `aria-label` (กระดิ่ง: "การแจ้งเตือน 3 รายการที่ยังไม่อ่าน")
- กราฟมีข้อมูลเดียวกันเป็นข้อความ/ตาราง (`sr-only` หรือ toggle "ดูเป็นตาราง")
- ปฏิทินใช้คีย์บอร์ดได้ · dialog กักโฟกัสและคืนโฟกัสเมื่อปิด
- ทดสอบที่ 375, 768, 1280, 1440px

## 9. Copy

- เรียกสิ่งต่าง ๆ ตามที่ผู้ใช้เรียก: "รายการ" (ไม่ใช่ subscription), "ตัดเงิน", "รอบบิล", "ทดลองใช้ฟรี", "หารค่าบริการ"
- ประโยคสั้น มีตัวเลขจริง: "อีก 3 วัน Netflix จะตัดเงิน ฿419" ไม่ใช่ "คุณมีการชำระเงินที่กำลังจะมาถึง"
- ห้าม: "จัดการง่าย ๆ เพียงปลายนิ้ว", "โซลูชันครบวงจร", "ยกระดับ…", "เริ่มต้นใช้งานฟรี"
- Landing headline ใช้คำถามของแอปเอง: **"เดือนนี้โดนตัดเงินอะไรบ้าง?"** + ประโยครองที่บอกสามอย่างที่ทำได้จริง: "รวมทุกรายการไว้ที่เดียว เตือนทางอีเมลก่อนตัดเงิน และหารค่า Family plan กับเพื่อนด้วย QR พร้อมเพย์"
