# ตัดยัง?

เว็บแอปช่วยจำว่า **เดือนนี้โดนตัดเงินค่า subscription อะไรบ้าง** — รวม Netflix, Spotify, iCloud+, ChatGPT และบริการอื่น ๆ ที่สมัครไว้มาไว้ในที่เดียว แล้วเตือนทางอีเมลก่อนถึงวันตัดเงิน

## ภาพรวม

คนส่วนใหญ่สมัครบริการรายเดือนไว้หลายเจ้า แต่จำไม่ได้ว่าเจ้าไหนตัดเงินวันไหน หรือช่วงทดลองใช้ฟรีหมดเมื่อไร "ตัดยัง?" ช่วยเรื่องนี้

- **ผู้ใช้** เพิ่มรายการจากรวมบริการกว่า 37 บริการ (มีราคาเป็นเงินบาทและวิธียกเลิก) หรือเพิ่มเอง แล้วดูได้ว่าเดือนนี้จ่ายเท่าไร จะตัดเงินวันไหนในปฏิทิน และดาวน์โหลดสรุปรายเดือนเป็น PDF
- **แจ้งเตือน** ส่งอีเมลก่อนตัดเงิน 1, 3 หรือ 7 วัน และก่อนช่วงทดลองใช้ฟรีหมด พร้อมกระดิ่งแจ้งเตือนในเว็บ
- **หารค่าบริการ** หาร Family plan กับเพื่อน ส่งลิงก์ให้แต่ละคนจ่ายผ่าน QR พร้อมเพย์ที่ใส่ยอดให้แล้ว
- **ตัวช่วยประหยัด** แนะนำแพ็กเกจที่ถูกกว่า เช่น เปลี่ยนเป็นรายปี หรือหารกับเพื่อน
- **หลังบ้าน (Admin)** จัดการหมวด บริการ แพ็กเกจ และผู้ใช้ ดูสถิติระบบ และตอบข้อความแจ้งปัญหาจากผู้ใช้

## Stack

| ส่วน               | ใช้อะไร                                                       | ทำหน้าที่                               |
| ------------------ | ------------------------------------------------------------- | --------------------------------------- |
| Frontend + Backend | **Next.js 16** (App Router) + **React 19** + **TypeScript**   | หน้าเว็บและ API อยู่ในโปรเจกต์เดียว     |
| หน้าตา             | **Tailwind CSS 4**                                            | ธีมมืด รองรับมือถือถึงจอใหญ่            |
| ฐานข้อมูล          | **MySQL 8.4** + **Drizzle ORM**                               | เก็บผู้ใช้ รายการ กลุ่มหาร การแจ้งเตือน |
| ยืนยันตัวตน        | รหัสผ่าน (bcrypt) + session ใน cookie (JWT) · เข้าด้วย Google | แยกสิทธิ์ผู้ใช้ทั่วไป / ผู้ดูแลระบบ     |
| อีเมล              | Nodemailer (Gmail) + node-cron                                | งานเตือนรายวัน 08:00                    |
| ตรวจข้อมูล         | Zod                                                           | ใช้ชุดเดียวกันทั้งฟอร์มและ API          |
| ทดสอบ              | Vitest (unit + integration) · Playwright (E2E)                |                                         |
| ติดตั้งจริง        | Docker + Caddy (HTTPS อัตโนมัติ)                              |                                         |

วิธีติดตั้ง รัน และไฟล์สำหรับผู้ตรวจ (import SQL + บัญชีตัวอย่าง) อยู่ที่ [docs/06-setup.md](docs/06-setup.md)
